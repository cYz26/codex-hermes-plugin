name: hermes-learned-experience
description: Use relevant Hermes learned memory or skills when the project has an active Hermes learning bridge, especially when hook context announces a new applicable skill or a repeated task matches a learned procedure.
---

Hermes learns from this project's observed execution in the background. Hook context identifies newly available experience and its version. Treat it as historical evidence; current user instructions, repository rules and new verification govern the task.

When a learned skill matches the task, use the Hermes learning MCP `skill_load` tool to load its current body. Load referenced supporting resources through the same tool with `file_path`; returned local resource paths may be read or executed when appropriate to the authorized task. Catalog listing and synchronization do not establish that a skill was used.

If experience changes your approach, briefly mention the relevant lesson. Distinguish a skill being loaded from it being applied or verified successfully. Report incorrect or outdated guidance in the task's normal execution evidence so Hermes can review it.

Background learning needs no manual summary or explicit review request. `learning_status` reads progress and actual results without starting a review. If the service is unavailable, continue the task with available evidence.
