# Hermes Learning 0.10.0

0.10.0 将自然追加要求的自动学习与完整原生维护合并到同一版本。用户的初始目标、先前做法、追加要求和后续结果进入有来源的复盘；Hermes 继续负责模型复盘、Memory／Skills 写入、Curator 整理与恢复。

- 跨轮证据按原生 revision 截止，保留来源、迟到结论与缺失正文记录。
- 预算优先保护对话主线；来源标签不参与内容排名，工具结果配对与异模型裁剪继续保留覆盖说明。
- sidechat 只引用真实分叉前、已经留存且仍获准的父上下文。
- 技能修改核对相关性、原文引用和归类；当前意图所选 Memory／Skills 范围同时约束提示说明、工具和写入。
- 多页有界消费、缺失输入退避，以及按实际 revision 确认反馈覆盖，改善积压和进度报告。
- 原生 Curator 的合并、来源、别名、归档恢复与交付快照留存一并保留。过期原文引用的归档凭证副本同步退休；重复复盘不会不断扩充工具说明。

项目主分支的其他改动包括原生生命周期完整适配、复盘范围隔离和定期审查方案文档。本次没有更换 provider、模型、预算、认证、更新策略或日报调度，也没有批准历史记忆提案。

验证按层记录，完整摘要见 [0.10.0 检查与升级记录](../evidence/releases/0.10.0.json)。历史依据见 [自动反馈开发验证](./AUTOMATIC-FEEDBACK-VALIDATION.zh-CN.md)与 [0.9.0 原生维护记录](../evidence/releases/native-lifecycle-0.9.0.json)，保留各自版本。

本次[生成的方法](../evidence/releases/0.10.0/learned-method.md)与[结构化计划](../evidence/releases/0.10.0/plans.json)来自独立合成 home，复用既有 `custom:ark`／`ark:gpt-6-1-sol` 配置和预算，没有导入生产知识。

真实模型合成实验与受控计划变化不等于业务查询执行或 Desktop 跨聊天验收。生产 Curator 的语义质量仍需实际运行与应用证据观察，不能以服务可达或整理次数替代。

发布流程对稳定版本标签执行现有桥接、原生和 macOS 编译检查，全部通过后才生成 GitHub Release。安装仍使用[既有不可变安装与更新入口](./INSTALL.zh-CN.md)，在复盘边界替换 worker，保留当前学习数据与回退点。新插件的 hook 信任以宿主回读为准。

Codex 使用安装后的插件副本；新聊天加载新版工具定义。插件包与本地市场规则参考 [OpenAI 官方插件打包说明](https://developers.openai.com/plugins/build/plugins)，本机安装参数已按实际 CLI 帮助核对。
