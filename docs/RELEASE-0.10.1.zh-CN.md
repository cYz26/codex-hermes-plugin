# Hermes Learning 0.10.1

0.10.1 修复已有学习数据上的进度读取延迟。0.10.0 的查询将采集回合与全部保留回合通过 JSON 来源字段关联，导致生产状态读取约 5.2 秒，超过安装器的 2 秒核对时限。安装器拒绝切换并恢复了 0.9.0。

现在先选定进度页，再按回合主键读取状态，同时核对 host／project 来源。相同生产数据的只读查询约 0.18 秒；分页、来源隔离、候选与发布状态口径保持原样。新增回归使用 SQLite 指令预算检查有界读取，原查询复现失败，修正后通过。

这次修复继续保留原有启动核对、provider、模型、预算、更新策略和学习数据。自动反馈、原生 Curator、归档恢复和引用留存沿用 [0.10.0 的集成](./RELEASE-0.10.0.zh-CN.md)。原生算法与模型配置没有变更；真实模型实验保留在当时的 0.10.0 记录中。

GitHub 的 `macos-14` 运行器配置已不再支持，0.10.0 的标签流程因此取消。0.10.1 将同一组 Python 测试和 Swift 编译检查移到 `macos-15`，继续作为 Release 的必要条件。

验证记录见 [0.10.1 检查与升级结果](../evidence/releases/0.10.1.json)：335 项发布检查（11 项条件跳过），354 项原生、335 项完整桥接及 664 项站点适配测试全部通过，独立启动检查通过。实际安装回读在升级后补记；GitHub Release 仍由稳定标签工作流在桥接、原生及 macOS 检查通过后生成。
